# Codebase Map

- `jobs-spi/`: `com.jobsapply.spi.{common,profile,source,matching,render,application,llm}`.
  - Plugin contracts, plus the shared vocabulary enums (`EmploymentType`, `Availability`, `Eligibility`, ...).
  - `RoleProfileDefinition` (the YAML schema of role profiles) and `CandidateSnapshot` (versioned candidate facts) live here.
- `jobs-app/` (`com.jobsapply.platform`), one module per package:
  - `shared` (an OPEN module)
    - `id/Ids` (UUIDv7)
    - `persistence/BaseEntity`, `OwnedEntity` (@TenantId and the post-load guard)
    - `tenancy/UserContext` (ScopedValue) and the tenant resolver
    - `json/JsonCodec`
    - `error/*` and `web/GlobalExceptionHandler`
    - `model/Actor`, `UpsertOutcome`
    - `crypto/PersonalDataCipher` (AES-256-GCM plus HMAC) and `web/RedactingLogCustomizer`
  - `identity`: `UserService` and `AppUser`. `LocalUserBootstrap` creates the configured local user, and `LocalUserContextFilter` binds that user for `/api/*` in LOCAL mode.
  - `catalog`: `CatalogService` (job families, skills and aliases), `CatalogSnapshot`, `SkillExtractor` (whole-term matching in job text).
  - `plugin`: `PluginRegistry<T>` (fail-fast; deny-list `jobs.plugins.disabled`), `PluginSettingsBinder`. Registries are created in `internal/PluginRegistryConfiguration`.
  - `source`: `SourceService` (check against the installed adapters, upsert, list, IDs by key or adapter); `web/SourceController` (sources, plugins).
  - `employer`:
    - `EmployerService` (CRUD, declarative upsert with bindings, search, export, binding owners)
    - `EmployerPreferenceService` (per user)
    - `internal/EmployerSpecifications` (JPA Specification) and `EmployerSearch`
    - `EmployerSource` (bindings, moved here from `source`)
    - `UserEmployerPreference`
    - `web/*Controller`
  - `posting`: `ListingIngestService` (wrapping `internal/ListingIngestor`), `internal/JobNormalizer`, `PostingQueryService` with `internal/PostingSpecifications`, `web/PostingController`.
  - `discovery`:
    - `SyncService`, `internal/SyncEngine` (the algorithm), `internal/SyncRunRecorder` (REQUIRES_NEW history), `internal/SyncRunRecovery`
    - `AvailabilityService`, `SyncRunQueryService`
    - `web/DiscoveryController`
  - `roleprofile`: `RoleProfileService` (idempotent versioned import; visibility is "own profiles plus templates").
  - `candidate`:
    - `CandidateProfileService`: encrypted immutable versions, import, `verifyFacts`, detail and versions views
    - `CandidateSnapshots`, `CandidateSnapshotValidator`
    - `web/CandidateProfileController`
  - `matching`:
    - `MatchingService` (evaluate, run, list, get; idempotent `JobMatch` rows)
    - `internal/RegistryMatchingVocabulary`
    - `web/MatchController`
    - Rules, components and strategies are plugins in `jobs-adapters/.../matching`.
  - `application`: the `ApplicationStatus` transition table, the `Application` aggregate (`discover`, `transitionTo`) and its history.
  - `preparation`:
    - `PreparationService` (prepare, answer, editResume, reject, views, download)
    - `TraceabilityValidator`, `PackageContent`
    - `ResumeTemplateService` / `ResumeTemplateSpec`
    - `internal/ApplicationPackage` and `ApplicationDocument` (immutable, encrypted)
    - `web/ApplicationController`
  - `application`:
    - `ApplicationService`: `openOrCreate`, `transition` (approval and submission states blocked), `recordPreparation`, `approve`, `revokeApproval`, `startSubmission`, `recordOutcome`, `verify`, `markInterrupted`, `withdraw`, views
    - `internal/SubmissionApproval` and `ApplicationAttempt` (evidence encrypted)
    - `ApplicationEvents`, `SubmissionEvidence` (`credible()`)
  - `assist`:
    - `AssistService`: start, refresh, confirm, close, view, screenshot
    - `internal/FieldMappingPlanner` (policy), `AssistSessions` and `LiveSession` (in memory, one per user), `PlatformSession`, `AssistWindowCloser`
    - `web/AssistController`
  - `identity`: `UserService` (createUser/createAccount, setUpFirstAccount, change/reset password, disable, list), `internal/SecurityConfiguration` (filter chain, roles, CSP), `AccountDetailsService`, `LoginAttempts`, `UserContextFilter`, `CsrfCookieFilter`, `web/AuthController`, `web/AdminUserController`.
  - `tracking`: `TrackingService` (contacts, interviews, follow-ups, summary), `internal/Contact|Interview|FollowUp` (+ encrypted `Details`), `web/TrackingController`.
  - `shared/web/DashboardRoutes` (SPA routes → index.html, asset caching), `shared/web/OpenApiConfiguration` (nested schema names).
  - `submission`:
    - `SubmissionService`: gates, approve, revoke, start (returns the application link), outcome, verify, withdraw
    - `internal/SubmissionRecovery`: startup recovery and the only cross-user scan
    - `web/SubmissionController`
  - `candidate`: also `MasterResumeService` and `web/MasterResumeController`.
  - `shared/storage/DocumentStore`: encrypted, write-once files under `jobs.storage.directory`.
  - `audit`: `AuditEvent` (`subject_user_id`), `internal/AuditRecorder` (synchronous `@EventListener`, ids and codes only), `AuditService.mine`, `web/AuditController` (`GET /me/audit`).
  - `configimport`: `ConfigImportService` (directory, single YAML document, CSV content), `EmployerExchangeService` (CSV import; CSV/YAML export), `internal/EmployerCsv`, `web/ConfigController`, `internal/ConfigLoader` (YAML → envelope → upgraders → record → Bean Validation), `internal/SemanticValidator` (cross-document rules), `internal/ConfigStartupRunner`.
- `jobs-adapters/` (`com.jobsapply.adapters`):
  - `http/` holds `HttpFetcher`, `HostRateLimiter`, `HttpTransport`/`JdkHttpTransport`, `AbstractHttpJobSourceAdapter` and `Json`.
  - `source/{greenhouse,lever,ashby}` hold the adapters.
  - `matching/` holds the rules, components and strategy; `preparation/` the resume, cover-note and answer plugins; `render/` the HTML and PDF renderers.
  - `BuiltInAdaptersAutoConfiguration` is registered via `META-INF/spring/...AutoConfiguration.imports`.
  - Tests use `FakeTransport` and `src/test/resources/fixtures`. `live/PublicBoardsLiveIT` runs with `-Plive`.
- Migrations: `jobs-app/src/main/resources/db/migration/V1..V8`.
- Tests:
  - Unit tests are `*Test`. Integration tests are `*IT` (`support/IntegrationTest`, `ApiTest`, `TestData`, `DbAssertions`, `HttpApi`).
  - Discovery tests use `support/ScriptedJobSourceAdapter` and `DiscoveryFixture`.
  - `RealSourcesLiveIT` runs only with `-Plive`.
  - The architecture tests are `ModularityTest`, `PersistenceRulesTest` and `SpiDependencyRulesTest`.
- `config/`: sample YAML (example role profiles, fictional disabled employers).
- `jobs-browser`: `PlaywrightApplicationAdapter` (single browser thread; `actAsHuman` test hook), `BrowserSettings` (`jobs.browser.*`), `inspect-form.js`, `BrowserAssistAutoConfiguration`. Tests: `PlaywrightApplicationAdapterIT` with fixture forms in `src/test/resources/forms`.
- `jobs-web`: React dashboard. `src/api/client.ts` (openapi-fetch, CSRF, ApiError), `src/api/openapi.json` (contract snapshot; `schema.d.ts` generated), `src/auth/session.tsx`, `src/pages/*` (one per route), `src/components/*` (PackageReview, SubmissionPanel incl. AssistPanel/OutcomeForm, ApplicationTracking, ui), tests `*.test.tsx` (Vitest, `src/test/fetchMock.ts`). Built by frontend-maven-plugin into `target/classes/static`.
